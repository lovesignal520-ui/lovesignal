# LoveSignal content QA checklist

Run this checklist every time you add or update a show.

- [ ] Use the official English title and a unique lowercase ID.
- [ ] Write an original description; do not copy another database.
- [ ] Confirm country/category, year and Airing/Completed status.
- [ ] Count `episodeLinks` and make `episodesCount` match.
- [ ] Open every external link in a private browser window.
- [ ] Use only official or authorized episode sources.
- [ ] Confirm poster and hero URLs are direct image files and load without hotlink errors.
- [ ] Compress local images; avoid huge base64 strings inside `app.js`.
- [ ] Add useful tags that match the words visitors may search.
- [ ] Check the page on a phone and desktop.
- [ ] Update `sitemap.xml` when adding a new permanent HTML guide page.
- [ ] Add a clear affiliate/sponsored label beside any compensated link.
